快捷键与使用提示

列
⌘ N新建列 ⌘ W关闭当前列（有任务在跑会先确认） ⌘ 1…9跳到第 N 列 ⌘ ← ⌘ →左右切换聚焦列 ⌘ J跳到等你回复的列（红点），多列循环 ⌘ ⏎放大 / 还原当前列（双击列头空白处同效） ⌘/Ctrl + −终端字体加减，0 复位（全列生效，会记住） 双击列名重命名（Enter 确认，Esc 取消） 自动命名给 agent 发任务后，列名自动变成任务摘要；手动改过名的列不再自动变 弹窗通知窗口不在前台时，非 Claude 列（agy/grok…）变绿/变红会弹窗，点击直达该列（Windows；Claude 列走自己的 hook 弹窗） 拖动 ⠿ 把手拖拽排序（侧边栏条目也可以拖）
输入与搜索
⌘ F列内搜索（Enter 下一个，Shift+Enter 上一个） ⌘ B广播：同一条输入发给所有列 ⌘ V粘贴截图 → 自动存成 PNG 并输入其路径 拖文件进列自动输入该文件的路径 ⌘ 点击 URL用浏览器打开 点击路径在访达中显示 ⌥ 点击 路径用编辑器打开并跳到 :行号
状态灯
灰 = 未开始 黄（呼吸）= AI 干活中 红（闪烁）= 等你回复 — Dock 角标同步计数 绿 = 已完成 空心 = 进程已退出
